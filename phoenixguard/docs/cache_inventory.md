# Cache Inventory

Agent 1 did not clear caches. This inventory classifies known paths for the required V3 cache migration.

## Preserve

| Path or pattern | Reason |
| --- | --- |
| `models/`, `*.pt`, `*.pth`, `*.onnx`, `*.safetensors` | Model weights and exported runtimes |
| `yolov8n.pt` | Root model asset |
| `.hf_cache/` | Downloaded model cache; preserve unless explicitly rebuilding model environment |
| `memory_bank/metadata.json`, `memory_bank/index/id_map.json`, `memory_bank/index/*.npy` | Memory bank source/index data |
| `memory_bank/BUYS`, `memory_bank/SELLS`, source examples | Labelled training data |
| `data_splits/` manifests | Training/eval split artifacts |
| `808_shooter_boxes.json` | User calibration points |
| `user_calibration_manifest.json` | Authoritative calibration manifest |
| root config files and deployment env examples | User/project configuration |

## Backup Then Clear For V3 Migration

| Path or pattern | Reason |
| --- | --- |
| `data/mobile_api/observer/sessions/*/session.json` | Old observer latest state can contain raw signal fields |
| `data/mobile_api/window_tracker/sessions/*/session.json` | Old tracker state can contain stale latest signal and frame counters |
| `data/mobile_api/**/bundles/*/bundle.json` | Old observer bundle state |
| `data/mobile_api/jobs/*/job.json` and `result.json` | Old manual job outputs |
| `data/capture_recovery_state.json` | Runtime recovery state |

| `data/manual_inference_jobs.json` | Manual inference queue/cache |

| `data/feedback_feed.jsonl` | Feedback feed, preserve only if training migration consumes it |
| `.codex_runtime/tracker_status.json` | Launcher status from previous runtime |
| `shooter_3_gate_state.json` | Shooter gate state, if present |

## Safe To Clear

| Path or pattern | Reason |
| --- | --- |
| `__pycache__/`, `**/__pycache__/` | Python bytecode cache |
| `.pytest_cache/` | Test cache |
| `tmp/`, `tmp-debug/` | Temporary artifacts |
| generated preview/cache files under `data/mobile_api/**/artifacts` | Regenerated by tracker/observer |

## Review Before Clearing

| Path or pattern | Reason |
| --- | --- |
| `data/personalization_profiles.json` | May contain user preference/training state |
| `logs/*.log`, `shooter_debug.log*`, `replay_trace.log` | Forensic value; archive before clearing |
| `memory_bank/decisions.log` | Shooter decision history; archive for bad-entry regression |
| `memory_bank/audit_hash_chain.log` | Audit trail |

## In-Memory Caches Found

- `main.py`: `_local_ensemble_cache`, `_local_ensemble_future_cache`, `_local_ensemble_error_cache`, `_compare_frame_uri_cache`, `_zone_memory_cache`, `_capture_runtime_state`.
- `phoenixguard/runtime/model_council_daemon.py`: `_runtime_cache`, `_prediction_cache`.
- `phoenixguard/runtime/local_ensemble_runtime.py`: resident runtime/model cache.

## Required V3 Addition

All durable cached objects that survive the V3 migration must carry:

`cache_schema_version = PG_CACHE_V3_MODEL_COUNCIL_EXECUTION`

They must also include session, symbol, timeframe, frame/capture/state counters, input/viewport hashes, model/preprocess hashes, decision schema, and calibration profile id.
