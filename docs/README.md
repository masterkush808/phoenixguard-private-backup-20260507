# PhoenixGuard Docs

PhoenixGuard documentation is grouped by operating surface:

- `architecture/` - system maps, blueprint, and generated architecture PDF.
- `scenarios/` - A-star scenario engine guides, manifest, quick reference, and integration examples.
- `share/` - share frontend and Cloudflare exposure guides.
- `tracker/` - live tracker user guide, debug summary, and trade triggering notes.
- `vision/` - vision/CV upgrade plans, delivery notes, and implementation references.
- `window_tracker_deep_dive.md` and `window_tracker_v2_architecture_spec.md` - deep technical tracker specs.
